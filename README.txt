MAISON PRIVÉE — SITE VITRINE GRATUIT

Fichiers : index.html, styles.css, script.js, mentions-legales.html

PRÉVISUALISATION : ouvrir index.html dans un navigateur sur ordinateur.

PUBLICATION GRATUITE AVEC GITHUB PAGES :
1. Créer un compte GitHub (gratuit) si nécessaire.
2. Créer un dépôt PUBLIC, par exemple maison-privee-site.
3. Importer les 4 fichiers à la racine du dépôt.
4. Dans Settings > Pages > Build and deployment, choisir Deploy from a branch, branche main, dossier / (root), puis Save.
5. Le site sera accessible à une adresse de type https://NOM-UTILISATEUR.github.io/maison-privee-site/ (le nom exact dépend de votre compte et du dépôt).
